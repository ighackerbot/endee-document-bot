# Endee Vector Database Overview
Endee is a high-performance, open-source vector database built for AI applications. It helps developers store and search massive quantities of unstructured data using vector embeddings.

## Key Features
- **Semantic Search**: Find documents based on their meaning, not just keywords. Endee uses cosine similarity for dense vector search.
- **Hybrid Search**: Combine vector similarity with metadata filtering, like filtering searches by date, category, or specific document IDs.
- **High Performance**: Designed from the ground up for low-latency retrieval, even with millions of vectors. Supports INT8 quantization.
- **RAG Ready**: The perfect backend for Retrieval-Augmented Generation workflows. Store document chunks and retrieve them to build context for LLMs like Gemini or GPT-4.

## Getting Started
To use Endee, you first initialize an index specifying the vector dimension and space type. Then you can insert data using `index.upsert()`. For querying, use `index.query(vector=..., top_k=5)`.
